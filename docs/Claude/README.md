## 平台一句话定位

> 为 AI 影视制作搭建可复制的创作引擎 —— 用可视化画布探索创意，用确定性流程交付作品。把灵感与产出分离，让每一次生成都可追溯、可复用。

## 端到端核心流水线

```
剧本文本
  → split 剧集拆分
  → extract 提取主体(角色/场景/道具/声音 + AI描述)
  → merge 跨集合并(子主体去重)
  → enrich 设计线索增强(扩成摄影级生图 prompt)
  → parents 归纳父主体(形态聚合)
  → 资产库: 主体生图候选(GPT Image 2 / Nano Banana) → 审核 → 通过1张为 image_entry; 挂载声音
  → 创作画布: 设计/排布主体图节点
  → 分镜生成: 每集 LLM 拆 场景→镜头组→镜头(摄影级 prompt + 引用主体 + 配音元素 + 首/尾帧连续性)
  → 视频生成: 每镜头组 prompt + 引用主体设计图 → Seedance 2.0 多参考图图生视频(异步 job, 积分预扣)
  → 时间线编排: 片段排序 + trim 裁剪 → 合成成片
```

| 图生视频 | `doubao-seedance-2-0-260128` (Seedance 2.0, 字节) | 镜头组多参考图生视频 (provider: jianyu / modelsai, job_type: all_reference) |
