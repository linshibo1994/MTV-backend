# 服务器部署指南编写说明

## 目标

基于当前仓库的实际实现，产出一份可用于 Linux 服务器上线后端服务的部署指南。

## 约束

- 不读取真实 `.env`、密钥或生产配置，也不执行任何远程部署。
- 不修改应用业务代码、现有 Docker 配置或工作区中已有的未提交改动。
- 所有运行命令、环境变量和拓扑结论必须能追溯到仓库代码或配置。
- 明确区分当前可直接执行的主机部署方案与现有开发向 Docker 资产的限制。

## 验收标准

- 覆盖 PostgreSQL、Redis、FastAPI、Celery worker、Celery beat、媒体存储、AI 服务和 Nginx。
- 给出安装、配置、迁移、启动、健康验证、日志、备份、更新、回滚与排障步骤。
- 列出必填与按需环境变量，且不包含任何真实密钥。
- 标明生产安全要求与当前部署产物缺口。
