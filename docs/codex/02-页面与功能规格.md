# 页面与功能规格

## 1. 使用说明

本文件按页面定义复刻产品的可见结构与交互契约。每页均包含：路由、入口、布局、控件、数据、状态、风险和验收。`E1/E2/E3/D/U` 的含义见 [研究方法](./00-研究方法与证据索引.md)。

### 1.1 页面层级

```text
未登录
└─ 首页 / 登录弹窗

已登录工作台
├─ 剧本页
│  ├─ 剧本列表
│  ├─ 普通/新闻播报新建弹窗
│  └─ 剧本详情（分集 + 正文 + 主体）
├─ 资产库
│  ├─ 资产库列表
│  └─ 资产详情（父子主体 + 候选审核）
├─ 创作页
│  ├─ 创作项目列表/新建
│  └─ 节点画布
├─ 分镜库（隐藏入口）
│  └─ 分镜候选图工作台
├─ 视频页
│  ├─ 视频项目列表
│  └─ 视频工作台
│     ├─ 分镜结果
│     ├─ 镜头组合并
│     └─ 所有视频 + 时间线
├─ 新闻播报工作台（深层路由）
├─ 积分明细弹窗
└─ 账号管理（当前账号受限）
```

代表证据：全局/剧本见 `EV-SCRIPT-LIST-01`、`EV-SCRIPT-DETAIL-01`；资产见 `EV-ASSET-LIST-01`、`EV-ASSET-DETAIL-01`；画布见 `EV-CANVAS-BASE-01`；分镜/视频见 `EV-SHOT-WORKBENCH-01`、`EV-VIDEO-WORKBENCH-01`、`EV-VIDEO-ALL-01`；积分/权限见 `EV-CREDIT-UI-01`、`EV-CREDIT-UI-02`、`EV-CREDIT-UI-03`、`EV-ACCOUNT-DENIED-01`。前端代码能力分别见 `EV-CODE-ROUTE-01`、`EV-CODE-SCRIPT-01`、`EV-CODE-CANVAS-01`、`EV-CODE-VIDEO-01`、`EV-CODE-NEWS-01`、`EV-CODE-IMAGE-01`、`EV-CODE-CREDIT-01`、`EV-CODE-TECH-01`；完整路径索引见 [08-全平台探索覆盖清单.md](./08-全平台探索覆盖清单.md)。

## 2. 全局应用外壳 `APP-SHELL`

### 2.1 结构（E1）

桌面端为固定顶部导航 + 主内容区。深层剧本、资产和视频工作台仍显示顶栏。

| 区域 | 内容 | 行为 |
| --- | --- | --- |
| 左侧品牌 | 产品名称 | `D` 点击回默认工作区，而不是清空当前状态 |
| 中部导航 | 剧本页、资产库、创作页、视频页 | 当前模块有激活态；切换前处理未保存状态 |
| 右侧状态 | 在线状态、用户名、积分 | 积分可点击打开明细 |
| 右侧命令 | 退出图标 | `D` 有可访问名称与工具提示 |

### 2.2 全局行为

- `E1` 登录成功后默认进入剧本列表，没有独立仪表盘。
- `E2` 积分展示由账户余额减冻结积分得到。
- `E2` 当前实现约每 10 秒请求一次积分账户，页面静止也持续发生。
- `D` 使用推送更新积分；断线时最多一个自适应轮询器。
- `D` 顶栏显示全局作业入口、失败计数和需要审核的数量；原站未见该入口。
- `D` 所有图标按钮必须有 aria-label、焦点态和 tooltip。

### 2.3 全局状态

| 状态 | 目标 UI |
| --- | --- |
| 会话校验 | 居中骨架/进度，最长等待后给出重试，不无限显示“正在验证” |
| 断网 | 顶部非阻断横幅；编辑器进入本地草稿；高成本命令禁用 |
| 401 | 清理会话并跳登录，保留安全的目标路由 |
| 403 | 专用无权限页，不用空白或永远 Loading |
| 429 | 展示重试时间；禁止客户端高速重试 |
| 5xx | 保留用户输入，提供 request ID 与重试 |

### 2.4 验收

- 深层路由刷新后仍进入正确资源；未登录时登录后回原目标。
- 当前导航项、页面标题和浏览器标题一致。
- 任何模块出现错误不破坏顶栏和退出能力。
- 账户事件变化后 5 秒内更新积分，页面不可见时不产生无意义轮询。

## 3. 首页与登录 `AUTH-LOGIN`

**路由（E1）**：`/v3/home?next=/`

### 3.1 页面目的

未登录用户看到产品介绍首屏，并可打开管理员登录弹窗。登录成功后进入目标工作区。

### 3.2 登录弹窗

| 控件 | 规则 |
| --- | --- |
| 用户名 | 必填；首尾空格策略明确 |
| 密码 | 必填；默认掩码；允许显示/隐藏（D） |
| 登录按钮 | 字段完整且未提交时可用 |
| 错误信息 | 账号或密码错误使用统一文案，避免账号枚举 |
| 关闭 | 回到首页，不清理非敏感用户名是否保留由策略决定 |

### 3.3 安全要求（D）

- 登录限流、异常 IP/设备告警、可选 MFA；
- 成功后轮换会话标识；Cookie 为 HttpOnly/Secure/SameSite；
- 密码、Cookie、令牌不得进入 URL、前端日志或埋点；
- `next` 仅允许站内白名单路径，防开放重定向。

### 3.4 状态与验收

- 错误凭据只显示通用错误；连续失败触发渐进限流。
- 会话有效时访问登录页自动进入工作区。
- 登录请求进行中禁止重复提交；超时可恢复。

## 4. 剧本列表 `SCRIPT-LIST`

**路由（E1）**：`/v3/scripts`

**标题（E1）**：“剧本创作”；副标题为管理与创作说明。

### 4.1 布局

```text
标题 / 副标题                              [新建剧本]
[搜索..............................................]
[个人项目] [团队项目]
项目卡片网格或空态
```

### 4.2 控件与交互

| 控件 | 可观察行为 | 复刻要求 |
| --- | --- | --- |
| 搜索框 | E1/E2 服务端搜索，查询带 `q` | 300ms 防抖、取消旧请求、URL 保存关键词 |
| 个人/团队 Tab | E1 切换 `scope` | 每个 Tab 独立缓存页码与搜索 |
| 新建剧本 | 打开两种产品线弹窗 | 权限不足时隐藏并解释 |
| 项目卡片 | 标题、创建者、更新时间 | 补充状态、封面、作业提醒（D） |
| 卡片图标 | E1 直接打开删除确认，并非更多菜单 | 使用明确删除/归档图标与 tooltip |

### 4.3 数据

`E2`：`GET /scripts/page?limit=30&offset=0&scope=personal|team&q=...`，响应 `{items, next_offset}`。

`D` 列表项一次返回封面、分集数、主体审核统计、最近作业状态，避免后续逐卡请求。

### 4.4 页面状态

| 状态 | 原站 | 复刻目标 |
| --- | --- | --- |
| 个人初始空库 | U：本次未稳定观察个人首次空库 | 保留创建主行动 |
| 团队空库 | 空态 | 说明团队范围和权限 |
| 搜索无结果 | E1 复用初始空态 | 改为“未找到匹配项”，提供清除筛选 |
| 加载 | U | 卡片骨架且布局稳定 |
| 错误 | U | 保留搜索条件并可重试 |
| 有下一页 | 样本未触发 | 无限加载或分页均须防重复项 |

### 4.5 删除确认

`E1` 原站提示项目及关联数据永久丢失、不可撤销，操作是“我再想想/确认删除”。

`D` 推荐：

1. 默认软删除并提供恢复期；
2. 弹窗列出分集、资产、作业和成片影响；
3. 高价值项目要求输入项目名；
4. 删除命令幂等且记录审计；
5. 有运行中作业时先阻止或明确取消策略。

## 5. 新建剧本弹窗 `SCRIPT-CREATE`

### 5.1 通用结构（E1）

- 顶部类型切换：“默认 / 新闻播报”；
- 默认模式只有标题输入和“开始创作”；
- 空标题时主按钮禁用；
- 关闭不提交数据。

### 5.2 默认模式

| 字段 | 规则（D） |
| --- | --- |
| 标题 | 1-100 字，规范化空白，同作用域重名可允许但提示 |
| 作用域 | 默认个人；有团队权限时可选组织 |
| 初始分集 | 默认 1 集，正文为空 |

创建成功后进入首集详情；提交失败保留标题和错误。

### 5.3 新闻播报模式（E1/E2）

详见 [新闻播报制作流程](./04-新闻播报制作流程.md)。弹窗字段：

- 新闻文案；
- 主持人播报 / 纯场景播报；
- 480p / 720p / 1080p；
- 16:9 / 9:16；
- 女性 / 男性主持人；
- 可选主持人 PNG/JPEG/WebP；
- 可选约 10 秒 WAV/MP3 固定音色；
- 身份/服装锁定帮助文案（E1）；上传后是否出现独立可操作控件为 U；
- 英雄场景：不使用 / 片头 / 片尾；
- 纯场景模式可添加图片/视频并绑定文案锚点（E2）；
- 文案为空时“一键生成”禁用。

`E1` 可观察默认值为主持人播报、720p、16:9、女性、英雄场景片尾。`D` 默认值应按组织模板保存，并在提交前显示成本估算和授权确认。

## 6. 剧本详情 `SCRIPT-DETAIL`

**路由（E1）**：`/v3/scripts/{script_id}/episodes/{episode_id}`

### 6.1 三栏布局（E1）

```text
[返回] 当前集标题                       [保存] [查看资产库]
主体提取进度 / 合并进度
┌────────────┬─────────────────────┬──────────────────┐
│ 分集栏      │ 剧本文本/编辑器       │ 主体列表           │
│ 搜索        │ 实体高亮               │ 全部/角色/场景/... │
│ 新增一集    │ 类型图例               │ 新增/卡片/操作      │
│ 集列表/删除 │ 文本输入               │ 描述/出现集数       │
└────────────┴─────────────────────┴──────────────────┘
```

### 6.2 顶部

| 控件 | 行为 |
| --- | --- |
| 返回 | 回剧本列表；有脏状态时提示 |
| 当前集标题 | 对应分集；切集更新 URL |
| 保存 | E1 无修改时禁用；D 使用 HTTP `If-Match` 携带当前资源版本 |
| 查看资产库 | 进入同剧本资产详情 |
| 状态条 | E1 显示主体提取进度与合并状态 |

### 6.3 分集栏

- 分集搜索、总集数、分集按钮；
- 新增一集；
- 每集删除入口；
- `D` 支持键盘排序、重命名、软删除与撤销；
- `D` 切集前自动保存草稿或阻止离开，不能静默丢文本。

### 6.4 文本区

- `E1` 阅读态按角色/场景/道具/声音高亮并显示图例；
- `E1` 编辑态为文本输入；
- `D` 高亮必须基于主体 span 与文本版本，文本变化后过期 span 不应错位；
- `D` 编辑器显示字数、保存状态、版本冲突和影响分析；
- `D` 超长剧本分段渲染，避免一次构建所有高亮 DOM。

### 6.5 主体栏

- 全部、角色、场景、道具、声音筛选；
- 卡片显示类型、名称、出现集数、描述和删除入口；
- 新增主体入口；
- `D` 编辑主体时校验同义词、父主体、形态和已有资产引用；
- `D` 被分镜/资产引用的主体不可硬删除，只能合并、归档或替换。

### 6.6 分析流水线（E2/D）

阶段：`split -> extract -> merge -> enrich -> parents`。

目标页面使用独立 `EpisodeAnalysisAggregateState`，不把 Job 与 Stage 的状态塞进同一字段：

| 聚合状态（D） | 派生依据 | UI（D） |
| --- | --- | --- |
| `pending` | 尚无分析 Job | 灰色等待，显示上游依赖 |
| `processing` | 最新 Job 为 `queued/running/cancel_requested` | 同时展示公开 Job 状态、当前 Stage、耗时和最近心跳 |
| `ready` | 最新 Job 为 `succeeded` 且当前输入版本已有完整结果 | 完成时间和结果摘要 |
| `failed` | 最新 Job 为 `failed` | 错误类别、人工重试入口和保留人工修改策略 |
| `canceled` | 最新 Job 为 `canceled` | 取消结果、账务收敛状态和重新分析入口 |
| `stale` | 已有结果的上游文本版本改变 | 说明需重算范围，旧结果保持只读可追踪 |

五个流水线阶段各自使用 `StageStatus`；公开作业只使用 `PublicJobStatus`。页面可组合展示二者，但服务端不得共用一个枚举列。

### 6.7 API（E2）

- `GET /scripts/{id}`
- `GET /scripts/{id}/episodes`
- `GET /scripts/{id}/pipeline-status`
- `GET /scripts/{id}/extract-subjects-status`
- `GET /scripts/{id}/episodes/{episode_id}/breakdown`

## 7. 资产库列表 `ASSET-LIBRARY-LIST`

**路由（E1）**：`/v3/asset-library`

**标题（E1）**：“资产库”；副标题为管理剧本关联的资产集合。

### 7.1 页面结构

- 搜索；
- 个人/团队项目 Tab；
- 资产库卡片：封面、剧本标题、“资产库”标签、更新时间；
- 点击卡片进入资产详情。

### 7.2 数据风险

`E2` 页面先请求剧本列表，再为每个项目单独请求 `GET /scripts/{id}/asset/entries?limit=1&offset=0`，形成逐项目资产条目/元数据附加读取的 N+1；该响应在页面中的唯一用途未完全验证，不能只断言为获取封面。

`D` 使用聚合列表：

```ts
interface AssetLibraryListItem {
  script_id: string;
  title: string;
  cover_thumbnail_url: string | null;
  subject_counts: Record<string, number>;
  reviewable_count: number;
  updated_at: string;
}
```

### 7.3 状态

- 团队空态（E1）：“暂无剧本/没有找到相关的剧本资产库”，无创建按钮；
- 搜索无结果需要独立空态（D）；
- 封面失败显示稳定占位和重试，不影响卡片尺寸；
- 聚合统计的加载/错误不能导致每张卡片抖动。

## 8. 资产详情 `ASSET-DETAIL`

**路由（E1）**：`/v3/asset-library/{script_id}`

### 8.1 顶部与统计

- 返回、项目名、添加、去设计；
- 已审核、未审核、全部主体统计；
- `D` “添加”和“去设计”写明结果：新增主体 vs 进入画布。

### 8.2 分组与表格（E1）

- 父主体分组，每组展示多个形态/子主体；
- 其余子主体单独区域；
- 列：图片、主体名、主体类别、描述、声音、所属集数、资产审核、审核状态、操作；
- 行内类别下拉、描述入口、审核入口和删除主体入口。

`E1/E2` UI 统计行数与 API 主体总数可能不同，差异主要与音频主体/父主体口径有关。`D` 筛选、统计、分页必须共享同一查询口径，并明确是否包含父主体和声音。

### 8.3 主体状态、UI 标签与动作（E1/E2）

原站同一行同时包含主体 API 状态、展示标签、候选数量和审核动作，不能简单一一映射：

| 主体 API `review_status` | 样本 UI 状态标签 | 样本动作表现 | 结论边界 |
| --- | --- | --- | --- |
| `not_designed` | “未通过” | “审核资产” | 没有正式通过资产；是否有其他设计入口取决于行状态 |
| `reviewable` | 仍可能显示“未通过” | “可审核 N” | 有候选可打开审核，N 来自候选计数 |
| `approved` | “已通过图片”等媒介级标签 | 仍可能显示“审核资产” | 已有正式版本，但审核弹窗仍可查看候选/当前版本 |

`E2` 候选条目样本状态为 `pending`，它与主体的 `not_designed/reviewable/approved` 不是同一状态机。

`D` 复刻时建议把候选状态规范化为 `draft/submitted/approved/rejected/withdrawn`，并通过适配层将原站式 `pending` 映射到明确的“已提交待审”状态。UI 应分别读取“主体设计状态、图片通过状态、声音通过状态、候选数量和允许动作”，不从一个标签反推全部业务状态。

### 8.4 审核弹窗

`E1` 结构：标题“资产审核”、主体名说明、图片区、声音区、当前选中/候选、待审/已通过标识和从审核队列删除入口。

`D` 目标交互：

1. 左侧当前正式版本，右侧候选对比；
2. 图片支持缩放、前后对比和元数据；音频支持波形/试听；
3. 通过、驳回、撤回是明确命令，需理由和权限；
4. 已通过资产不显示无说明的“从队列删除”；
5. 切换正式版本前显示被哪些镜头引用；
6. 弹窗关闭后恢复焦点。

### 8.5 API（E2）

- `/scripts/{id}/asset-library/subjects?limit=200&offset=0`
- `/scripts/{id}/asset-library/parent-subjects`
- `/scripts/{id}/episodes`
- `/scripts/{id}/asset-library/subjects/{subject_id}/review-candidates`

## 9. 创作项目列表 `MATERIAL-LIST`

**路由（E1/E2）**：`/v3/materials`

### 9.1 页面目的

管理用于图片/素材设计的创作项目。`E1` 项目可关联剧本，也可不关联剧本。

### 9.2 控件

- 项目列表/卡片；
- 新建入口；
- 新建时填写名称并可选关联剧本；
- 点击进入画布；
- `D` 显示保存状态、节点数、待审核数、最近作业和关联剧本。

### 9.3 性能风险

`E2` 观察到素材列表可能预取多个项目画布和封面。`D` 列表只请求摘要；画布快照在进入详情后加载；封面使用聚合缩略图接口和并发限制。

### 9.4 状态

- 无项目：提供创建；

- 业务节点修改才进入 delta；选择、视口、面板折叠保存为用户偏好；

- 支持撤销/重做，服务端审计命令而非每个鼠标移动；

- `D` 提交审核属于写命令，显示将提交的数量和主体；

## 22. 响应式与可访问性

`U` 原始证据均为 1200x870 桌面视口，没有移动端证据。

`D` 目标断点：

| 宽度 | 行为 |
| --- | --- |
| >= 1440 | 三栏详情与右侧预览同时显示 |
| 1024-1439 | 侧栏可折叠，表格横向滚动 |
| 768-1023 | 列表和审核可用；画布/时间线提示横屏或桌面更佳 |
| < 768 | 支持查看进度、审核、播放和取消；复杂编辑提供受控简化视图 |

关键要求：

- 不依赖颜色表达状态；
- 焦点顺序与视觉顺序一致；
- 拖拽都有键盘替代；
- 滑杆有名称、当前值和增减按钮；
- 图标按钮有名称；
- Toast 同步到 aria-live，但高风险错误必须留在页面内。

## 23. 页面级冒烟验收

1. 未登录访问每个深层路由，登录后返回原路由。
2. 普通成员访问账号管理，稳定显示 403，网络不发生重试风暴。
3. 每个列表验证初始空态、搜索无结果、加载、错误和下一页。
4. 剧本详情切换分集，URL、正文、主体计数和脏状态一致。
5. 资产审核打开/关闭后焦点正确，未确认时没有写请求。
6. 画布只选择节点/缩放视口，不产生业务 delta；编辑节点才产生一次幂等 delta。
7. 高成本生成先估算和确认；双击只创建一个作业。
8. 视频作业 422 不自动高速重试；页面提供可读错误。
9. 时间线排序/裁剪刷新后恢复，缩放不改变业务数据。
10. 所有页面在 1440、1200、1024、768、390 宽度无文字遮挡和不可达命令。
